# Security Policy

This project is an **experimental specification and reference implementation**. It has not been security-audited and must not be relied on for production use.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Use GitHub's private reporting: on the repository page, open the **Security** tab and choose **Report a vulnerability**. If that is not possible, write to **gwokmt2q@gmail.com** with the subject "Windi security". Include what you found, how to reproduce it, and which version or commit is affected.

This is a volunteer-maintained project: there is no guaranteed response time, but reports are welcome and will be taken seriously.

## Scope

In scope: the specification text (design flaws that would weaken an implementation) and the code in `src/`.

Known limitations are listed in the README ("Limitations of this reference implementation"); reports about them are still useful if you can suggest a fix.
